Reports page

Common to both iterations

  • Side navigation: can be kept open or collapsed, instead of relying on tooltips.
  • Top bar: shows the page name and the FR/EN language toggle, moved to the top right because it applies to the whole site.
  • Search: suggestions appear below the search bar as you type, matching report titles, descriptions and tags.
  • Filters: the same filters as today, presented more clearly.
  • Ask MTM: a chat assistant. You can also drag and drop a report into it to ask questions about that report.
    • Reports shown in a grid or list view.
    • Separate preview and download buttons for both the full report and the summary.
    • Preview panel for the report or summary that can be resized, or hidden when not needed.

    Pros

    • Keeps the MTM team's current workflow for uploading reports.

    Cons

    • Report loading times may vary.
    • May reduce report downloads overall.
